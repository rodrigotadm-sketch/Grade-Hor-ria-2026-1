# Grade Horária Biomedicina — versão JSON

Arquivos:
- index.html: estrutura da página
- styles.css: padrão visual verde e responsivo
- script.js: filtros e renderização
- dados.json: único arquivo a editar para atualizar aulas e optativas

Uso:
1. Publique os quatro arquivos na mesma pasta.
2. Atualize somente dados.json nas próximas ofertas.
3. Para incorporar no WordPress, publique a pasta em GitHub Pages/servidor e use iframe.

Observação: a migração foi automatizada a partir do HTML legado. Campos vazios no post antigo permanecem vazios.
